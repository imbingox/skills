# Issue tracker

这是每个业务项目自己的配置，不是一个额外 skill。
已有 `docs/agents/issue-tracker.md`、`triage-labels.md`、`domain.md` 和 AGENTS.md / CLAUDE.md 中的指向继续有效。
无需删除或重建它们，也无需先运行独立 setup 命令。

配置模板与发布规则随 to-spec 安装，见 [内置 tracker 参考](../skills/engineering/to-spec/references/issue-tracker.md)。
明确 tracker、目标 owner/repo 或项目、现有标签和依赖关系表达即可；不存放密钥。
只预览时不写远端。缺少发布目标或工具不可用时报告未发布，不能假装创建成功或换一个平台。
