# Engineering

四个由用户显式调用的入口，其中 `setup` 是低频 bootstrap，另外三个是日常流程。

| Skill | 用途 |
| --- | --- |
| [setup](setup/SKILL.md) | 每 repo 一次：tracker / workflow / domain docs + 幂等 CLI statusline 检查。 |
| [grill-with-docs](grill-with-docs/SKILL.md) | 澄清外部行为与兼容性，按需记录术语 / ADR。 |
| [to-spec](to-spec/SKILL.md) | Proposed Changes + 完整 spec + 按规模拆票；支持仅 spec、只拆票。 |
| [implement](implement/SKILL.md) | Leaf / Parent 自动实施编排、独立 review 与 tracker 状态推进。 |
